## 真機驗證清單
### 2026-10-22 階段 2：Marker（B 級）
依據：手冊第三節 dlg_MarkerSetup、GS_Markers、Marker_Results。以下均待真機驗證；目前僅通過合成訊號及 offscreen 自我檢查。預設「現行 X1/X2」保留原四條游標與第一通道取樣點吸附；新增 Manual 與追蹤模式依選取來源的座標、刻度與單位換算。
| 項目 | 本程式做法／需與真機比對 |
|---|---|
| Manual 三模式與解析度 | X only 僅垂直線、Y only 僅水平線、X and Y 四線；滑鼠依顯示座標移動，不吸附樣本。比對放大後像素解析度、來源切換及來源平移；數位來源僅純函式提供 digital 不可用判定，現有檔案契約沒有數位來源資訊。 |
| Track Waveforms 吸附 | 手冊未載明最近點或內插；本程式取最近資料點，同距取右點。以非等距時間軸、陡峭邊緣、剛好半個樣本間隔比對 X 與 Y，確認真機是否內插及同距選點。 |
| 觸發參考與可動範圍 | 純函式以 trigger_t（預設 0）為中心，半徑 max(1 s, 一個螢幕寬)。範圍內選最近點，沒有樣本回報不可用；邊界不在樣本上時的處理手冊未載明。比對不同時基、非零觸發點、記錄截斷及兩 marker 均在螢幕外的差值。UI 使用來源 t=0，不把顯示平移當觸發點。 |
| Y marker 刻度與單位 | UI 由來源的每格刻度與垂直位置換算，衍生波形使用原單位（例如 V/s、V²）。比對改刻度、垂直平移、切換不同單位來源時的 Y1／Y2／ΔY；追蹤波形只允許拖 X，Y 由樣本決定。 |
| 差值與 Delta To | 固定 X1↔X2、Y1↔Y2；ΔX=X2−X1、ΔY=Y2−Y1。手冊未載明符號規則，本工具在 X1>X2 時保留負號，倒數亦負；ΔX=0 回 None（UI 顯示 —），Versus 波形不計算倒數。比對真機符號、零差顯示與配對方向；UI 尚無 Versus 波形。 |
| Track Measurements 最近新增與唯讀 | 純函式接收呼叫端提供的最近新增量測位置，過濾 NaN／inf 位置後保留全部有效標籤、禁止拖動；空清單不顯示。現有引擎只有統計結果，UI 尚未自動傳入量測位置；接口為 markers.set_measurements(source, positions)。手冊未載明多點配對，暫以前兩個輸入點產生差值，需比對單點、雙點、多點及新增／刪除量測後的追蹤行為。 |
| Track Measurements 各量測位置定義 | 逐項記錄真機顯示的點／線／圈選區：Rise/Fall Time、Slew Rate 的閾值交越；Period/Frequency/Duty/±Width 的邊緣；Vmax/Vmin 的極值及同值樣本；Vp-p/Vtop/Vbase/Vamp 的電平；Vavg/Vrms 的統計區間；Overshoot/Preshoot 的局部極值與平台。必須逐項確認位置、個數、順序與標籤，不能從單一統計值反推位置。未明確定義的細節均為「手冊未載明」。 |
| 未實作的讀值欄位 | 手冊的螢幕外 Y 讀值 "Off Screen"、Track Waveforms 的 ΔY/ΔX 欄位尚未實作，待真機比對顯示條件與格式。 |
| 隱藏垂直線與量測區間 | 非預設模式 Manual Y only、Track Measurements 隱藏的垂直線仍決定量測「游標區間」；目前未改變此行為，需驗證操作預期。 |
| 非預設模式通道表 | 所有非預設 Marker 模式皆清空通道表，Manual X 也失去各通道 @X1/@X2 讀值；預設模式仍保留 @t1/@t2。此限制僅記錄，尚未實作新模式的逐通道讀值。 |
| Track Waveforms 時間軸檢查成本 | 每次拖曳都對整個時間陣列做 diff；1M 點約 1.6 ms、20M 點約 31 ms。必要時改成載入時檢查一次，本階段只記錄，不改快取或載入流程。 |
| 同值峰次序（C 級，留階段 3） | 同值局部極值、FFT 同幅峰、同值最大／最小樣本的先後與編號手冊未載明。本階段不新增峰排序規則，待真機記錄後於階段 3 處理。 |
### 2026-10-22 階段 1：離線時間與電壓量測
依據：[Infiniium 手冊－量測功能與算法](reference/Infiniium手冊-量測功能與算法.md) 第一、二節、A-1～A-5、A-7～A-9 與第八節。以下皆待真機比對；合成訊號自我檢查通過不代表已通過真機驗證。此檔原已存在，保留既有清單與歷次上機紀錄，於此新增階段 1 項目。

共同比對條件：凍結同一筆擷取，匯出相同時間窗與原始樣本；記錄機型、韌體、取樣率、點數、時基、垂直刻度、Top/Base 模式、閾值與 Measure All Edges 設定。先對齊單一事件及 Rising／Falling，再比較多事件統計；本程式「目前」取顯示時間最靠近 t=0 的合格事件（含界限值）；範圍未跨 0 時改以範圍中點為參考，同距取較早事件。整筆記憶體與螢幕點數可能不同，須記錄儀器 Analyze All Data、zoom、資料縮減及量測窗設定。表內未指定的誤差界限應依受測儀器規格與樣本解析度訂定，不把合成測試的浮點容差當成真機容差。
| 量測名 | 手冊依據 | 本程式做法 | 需比對什麼 |
|---|---|---|---|
| Vmax | Maximum_Voltage、Calculating_Min_and_Max | 輸入時間窗全部樣本最大值 | 同筆資料的尖峰、截波及不同垂直解析度；確認螢幕與記憶體資料範圍差異。 |
| Vmin | Minimum_Voltage、Calculating_Min_and_Max | 輸入時間窗全部樣本最小值 | 同上，另測負向尖峰。 |
| Vp-p | Peak-to-Peak_Voltage | Vmax − Vmin | 方波、正弦、三角波及含過衝方波；確認不誤用 Top − Base。 |
| Vtop | Top_Voltage、Calculating_Top_and_Base；A-3 | 256 格直方圖最高 102 格找峰；峰次數 < 全部樣本 5% 回退 Vmax；格內取平均，左閉右開、末格含右界 | 峰佔比低於／等於／高於 5%、最高 40% 邊界及相鄰格端點。40% 格數取整、格內代表值、同高峰選擇手冊未載明，保留現法；另確認手冊 half／40% 措辭差異的實際行為。 |
| Vbase | Base_Voltage、Calculating_Top_and_Base；A-3 | 最低 102 格找峰，< 5% 回退 Vmin，其餘同 Vtop | 反相重做 Vtop 測試；特別確認門檻使用單一峰次數，而非整個低端區間累計次數。 |
| Vamp | Making_Voltage_Measurements、Calculating_Top_and_Base | Vtop − Vbase | 含過衝／下凹方波，確認與 Vp-p 分離且隨 Top/Base 模式一致變化。 |
| 10/50/90、20/50/80 閾值 | Calculating_Thresholds、dlg_MeasurementThreshold；A-4 | Base + 百分比 × (Top − Base) | 有 DC 偏移及不對稱振幅時的三閾值電壓；兩組設定均測。本階段不新增 Custom、Auto set、Snap to 0 選項。 |
| 邊緣交越 | Determining_Rising_and_Falling_Edges；A-1 | 完整穿越三閾值；相鄰兩點線性內插；忽略未完成過渡／毛刺 | 掃動訊號相對取樣時刻、閾值恰落樣本、帶雜訊及重複交越；內插法手冊未載明，保留線性，需確認儀器實際結果。 |
| Rise Time | Rise_Time；A-2 | 同一上升緣 t_upper − t_lower；優先至少四點（兩個中間點），皆不足時以括住樣本時間差顯示上界 < | 已知 10 µs 線性邊緣的 10–90% 為 8 µs、20–80% 為 6 µs；再測不足四點及可疑標示。 |
| Fall Time | Fall_Time；A-2 | 同一下降緣 t_lower − t_upper，點數不足顯示上界 <，規則同上 | 已知下降時間、不同取樣密度與兩組閾值；確認不完整末緣不納入。 |
| 上升／下降斜率 | Slew_Rate | 上下閾電壓差除以帶方向的交越時間差；上升為正、下降為負 | 線性 0→2 V／2→0 V、10 µs 邊緣應為 ±200000 V/s；點數不足時上升斜率顯示 >、下降斜率顯示 <（真值更負）；比對此與手冊不同的界限處理及儀器符號。 |
| Period | Period、Timing_Definitions；A-5 | 相鄰同方向完整邊緣中閾交越時間差 | 1 kHz、非 50% Duty、視窗首緣下降、缺首尾半週期，分別選 Rising／Falling；比較每個事件。 |
| Frequency | Frequency；A-5 | 各事件先算 1 / Period，再做統計 | 固定週期及變週期訊號；辨別頻率平均與平均週期倒數，確認儀器統計口徑。 |
| +Width | Positive_Width、Timing_Definitions | 上升中閾交越至下一下降中閾交越 | 1 ms 週期／25% Duty 應為 250 µs；測首緣下降與首尾不完整脈波。 |
| −Width | Negative_Pulse_Width、Timing_Definitions | 下降中閾交越至下一上升中閾交越 | 上例應為 750 µs；比較閾值切換、脈寬約佔螢幕 80% 時結果。 |
| Duty Cycle | Duty_Cycle；A-5 | 每一完整週期內 +Width / Period × 100；兩種起始方向皆算高電平佔比 | 25%、50%、75%，分別選 Rising／Falling；確認 Falling 不會變成負脈寬佔比。 |
| −Duty Cycle | Duty_Cycle | 100 − 工作週期；兩種方向皆算低電平佔比 | 25% 高電平應得 75%；雙向雙閾值比對。 |
| Vavg | Making_Voltage_Measurements、Average_Voltage、RMS_Voltage；第八節 2、3 | full 預設整段算術平均；cycles 取首末同向完整邊緣中閾交越之間 [起點, 終點) 全部樣本，不足一完整週期回 No edges；cycle 取顯示時間參考點最近邊緣起的一週期，不足回 EDGE | cycles 使用最左至最後同向緣，與手冊觸發參考點單週期模式不同；對齊模式，比對非整數週期、變動 DC、首緣下降、直流與不足週期。均勻次取樣比例手冊未載明。 |

#### 2026-10-16 第三輪：慢時基下 RUN→STOP 的最短等待時間（DSO-X 3014G，Auto 觸發）
規律：`:RUN` 在儀器**已在執行**時是空操作，立刻 `:STOP` 會凍結一筆完整畫面，永遠成功；但從 **STOP 重新 RUN** 之後，必須等「一整筆記錄（10 格 × 時基）」採完才能 `:STOP`，否則 `:WAVeform:PREamble?` 卡到逾時，且之後的擷取持續失敗，直到再 RUN 並等完一筆才恢復。
| 時基 | 記錄長度 | 從 STOP 重新 RUN 後的最短成功等待 |
|---|---|---|
| 5 ms/div | 0.05 s | 0.5 s |
| 20 ms/div | 0.2 s | 0.7 s（0.6 s 失敗） |
| 100 ms/div | 1 s | 2.0 s（1.5 s 失敗） |
| 500 ms/div | 5 s | 5.5 s（3 s 失敗） |
| 1 s/div | 10 s | 10.5 s（5.5 s 失敗） |
| 2 s/div | 20 s | 20.5 s（10.5 s 失敗） |
結論：最短等待 ≈ `10 × 時基 + 0.5 s`。目前 `infiniivision.py` 固定等 1.5 秒，在 ≥ 100 ms/div 且「剛從 STOP 重新 RUN」時不夠，會卡死。
已實作：driver 記錄自己上次寫 `:RUN` 的時間（`_run_state` 還原時），擷取前只補足 `10 × :TIMebase:SCALe? + 1 s` 的剩餘時間；時間未知（使用者手動按 RUN）時退回固定 1.5 秒。實測 5 ms／100 ms／500 ms/div 各連續擷取 3 次皆成功（慢時基連續擷取約 `10×時基+1` 秒）。未測：Normal 觸發（等不到觸發時是否永遠無法完成一筆）、Single、Roll 模式。
測試後時基已還原為 5 ms/div、觸發 AUTO、RUN 中。

- 結論：逐點邊緣序列高度相關，尚未發現邊緣偵測錯誤；σ 差異來源仍需確認。參考時脈含追蹤**未證實，且證據傾向非追蹤**；PLL 開工前先用 `scope_trend_1M.json` 比對頻譜比值是否平坦，再確認參考時脈與門檻定義。
- 儀器還原：Math 函數 1 回 `OPERation ADD`、`DISPlay 0`、`NMEasurement MEAS1`；`WAVeform:SOURce CHAN1`；仍為 STOP；錯誤佇列無錯。
- 限制：僅 10 MHz 方波、單一幅度、單一筆擷取；未驗 PRBS／眼圖／大抖動訊號。

### 第四輪：頻譜比值檢查（2026-10-25，PLL 開工前置）
- 方法：`scope_trend_1M.json` 的 ClockTIE 以離線上升緣時間對位取樣（延遲 +5 點，相關 0.967、998 筆）；離線 TIE 先去線性趨勢，兩序列各減平均、Hann 窗 rfft，分 8 等寬頻帶（每週期一點，頻帶 0–fs/2＝0–5 MHz，最低可解析約 10 kHz）算 H=ΣS·O*/Σ|O|²。
- 結果：H 各帶 0.81–0.87、能量比 0.84–0.91、相干 0.92–0.97，**整體平坦，低頻帶無衰減**。高通追蹤型參考時脈會在低頻 H≪1、高頻趨近 1，此資料不符。
- 結論：示波器 Clock TIE 的參考時脈不像含 PLL 追蹤；0.85 的比例是常數縮放（對應門檻／標度差異），非頻率依賴。此為 PLL 開工前置條件的結果：**不能以此樣本校準 PLL 頻寬**，PLL 僅依 Keysight 二階 PLL 文件與合成驗收實作。
- 限制：單一 10 MHz 方波、記錄僅 100 µs（最低約 10 kHz），低於此頻率的追蹤無法排除；腳本為一次性，未入庫。
