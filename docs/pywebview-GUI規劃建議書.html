1 摘要

  • 做法：pywebview 只當「原生視窗＋原生檔案對話框」。介面是純 HTML/JS（ES modules，不打包、不用 CDN），Python 後端沿用現有 instruments/ storage/ analysis/，完全不改。
  • 前後端只靠一份凍結契約溝通（api_contract.json + 型別文件）。前端用 mock 後端、後端用 FakeDriver，各自驗證，不必等對方。
  • 波形永遠不整包送前端。Python 依像素寬度做 min/max 降採樣，以二進位傳輸，縮放平移再重取。
  • Qt 版全程保留，到功能與跨平台驗收完成才切預設入口；可隨時回退。
  • 工作拆成 9 條 lane，每條只改自己名下檔案，可交給不同模型同時寫。契約凍結（P0）是唯一的單線瓶頸。
兩位規劃者都踩到、你需要先知道的事實
  • pywebview 6.2.1 與 pyobjc 已裝在 /opt/anaconda3，Mac 不必再裝東西。
  • Web 版仍然需要 PySide6。instruments/infiniivision.py 用 QImage/QBuffer 做截圖裁切與 HD3 反轉色（已用 grep 確認）。RULES 禁止 Pillow，所以首版不能把 PySide6 移出打包，也不能宣稱「完全脫離 Qt」。
  • zeroconf 目前沒裝在 anaconda（discovery 會靜默退化成只剩 VISA 列表）。這是既有問題，與本案無關，另案處理。
  • contracts.py 的 capture docstring 仍寫「還原 RUN/STOP」，與 RULES 第 9 條（擷取後維持 STOP）衝突。凍結檔不能改，記錄即可。
  • Windows 缺 WebView2 時 pywebview 會靜默退成 IE11，ES modules 不會執行，必須偵測並提示。

4 大資料策略（100M 點 × 4 通道）

  1. 原始資料只存在 Python。前端永遠拿不到整包。
  2. 伺服端 min/max 降採樣：GET /wave?ch&t0&t1&px。searchsorted 找索引區間、左右各多取一點避免邊緣斷線；點數 ≤ 2×px 直接回原始點；否則 np.minimum/maximum.reduceat 分桶；NaN 保留斷線語義；單通道上限 32,768 點。
  3. 單層金字塔：開檔工作對每個 >1M 點通道預算一次 factor-1024 的 min/max（100M 點 ≈ 98k 桶 ≈ 0.8 MB）。全覽走金字塔，O(px) 而非 O(n)。
  4. 二進位格式（/wave、/fft 共用，little-endian）： 
    uint32 n | uint32 mode(0=原始,1=包絡) | uint32 0 | uint32 0   ← 16 bytes
float64 x[n]   位移 16（8 對齊）  ← 時間要全精度
float32 lo[n]  位移 16+8n         ← 只拿來顯示
float32 hi[n]  位移 16+12n（原始模式 hi==lo）
    不用 JSON／base64（波形走 JSON 慢且有跳脫問題；base64 多 1/3 體積）。pywebview 的 js_api 回傳值是 json.dumps 後塞進 evaluate_js 字串，已查證，波形不可走這條。
  5. 縮放平移：取可見範圍左右各 +50%；拖曳先位移重畫（零延遲），超出範圍或縮放倍率變化 >2× 才重取（停頓 80–120 ms、每圖最多 1 個進行中請求、AbortController 只中止過期顯示請求）。FFT 同理，log 軸按對數等距分桶、排除 0 Hz。
  6. min/max 只是視覺預覽。游標讀值、量測、FFT、CSV 一律用全精度原始資料。
  7. NaN／inf 一律轉 null：Python json.dumps 會輸出 NaN，JS JSON.parse 直接報錯（必踩的坑）。
  8. Windows MIME 寫死：mimetypes 讀登錄檔，.js 可能變 text/plain 使 ES module 被拒；server.py 寫死 html/js/css/json/svg/png/bmp。
  9. 效能目標（待量測，不是保證）：全覽 4×100M 全部回來 <300 ms；放大到 1M 點視野每通道 <30 ms；每幀重畫 <16 ms；暖快取縮放重取 P95 ≤250 ms。
  10. 離線：資源全在 static/，不用 npm／CDN／web font（字型 PingFang TC, Microsoft JhengHei）。驗收 grep：grep -rnE "https?://" scope_tool/web/static | grep -v 127.0.0.1 = 0 筆。
記憶體界線要講清楚：前端降採樣成功 ≠ 100M×4 擷取與所有分析成功。driver 擷取仍回完整 CaptureResult（凍結契約），峰值記憶體不會因此下降；大型 CSV 的 np.unique 也有暫存成本。要在小 RAM 機器處理 100M×4，需另立串流擷取／分塊量測決策，不屬於「GUI 換皮」。

5 凍結的前後端契約（P0 產出，凍結後只有 lead 能改）

傳輸規則

  • RPC：POST /rpc/<method>?k=TOKEN，body 為 kwargs JSON。回應一律 200：{"ok":true,"result":…} 或 {"ok":false,"error":{"code","message","retryable"}}；token 錯 403、方法不存在 404。
  • 錯誤碼：ScopeError 用其訊息；RemoteDesktopError → REMOTE_DESKTOP（「請關閉遠端桌面連線後重試」）；BUSY；其他為「未預期錯誤：…」。
  • 工作型方法立即回 {"job":"j<N>"}，結果經事件回傳；前端 bridge.js 必須暫存「比 RPC 回應先到」的 job 事件。同一 request_id 重送回原工作，避免重複擷取／寫檔。
  • 安全：只綁 127.0.0.1＋secrets.token_urlsafe(16)。open_waveform、export_* 能讀寫任意路徑，token 擋掉本機其他網頁的 CSRF；不開萬用 CORS，只服務靜態白名單與已登記 blob。

座標定義（必須凍結，否則游標／匯出會對不上）

  • display_time = source_time + time_offset(dx)；display_y_div = source_value / scale_per_div + position_div。
  • Marker 請求的 x/y 用來源物理座標；傳統游標用顯示時間吸附第一通道，各通道讀值先扣自己的位移。
  • 波形 CSV 匯出維持現行行為：原始資料不套顯示位移，以游標時間切原始時間軸。

前端內部契約（同屬 P0 凍結）

  • bridge.js：call / job / on / fetchWave / fetchSpectrum / screenshotUrl / MOCK。
  • analysis/store.js：共享狀態（file, channels, selected, view, cursors, markerMode, threshold, fftResult, measurements）、set(patch, origin)（origin ∈ user／snap／program，防止吸附造成無限迴圈）、command / onCommand。各模組只透過 store 和 bridge 溝通，不互相 import 內部函式。三個 lane 不得同時擁有同一份游標真值。
  • 圖表核心與控制元件只發「意圖事件」：viewport.intent、channel.shift_intent、channel.scale_intent、cursor.intent、rf.intent。
  • 樣式 token 與 CSS class 名稱由 L0 寫進契約文件，L6 實作，其他 lane 只能引用。

契約自我檢查（機械驗證，防止偏離）

  • Python：Api＋Analysis 公開方法集合 == api_contract.json 的 methods，且 inspect.signature 參數名一致、兩者無重名。
  • JS：mock_backend.js 方法名 == 契約 methods。mock 不得各頁自行發明假 API。

11 遷移、驗證與回退

  1. P0–P3：只新增 scope_tool/web/、packaging/、新 .command。ui/、main.py、舊 .command 一行不動；兩版共用 ~/.scope_tool.json（鍵相同）。不同 GUI 不同程序，不同時占用同一儀器。
  2. P4 切換：打 git tag qt-final；舊 .command 改跑 web、Qt 版改名 _qt.command 保留一個週期；你確認後才刪 ui/ 與 main.py（此時 PySide6 仍因 QImage 留在相依，pyqtgraph 才下架）。
  3. 四層驗證：①Python 自檢＋契約案例（無 NaN／Infinity、重送、忙碌、亂序、世代隔離）；②瀏覽器 mock（失敗、取消、未連線、重複點擊、晚到結果）；③原生平台與效能（Win/Mac 完整流程、100M×4 分塊產生的測試 HDF5、中文／長路徑、拔網）；④真機與真人（沿用 docs/真機驗證清單.md，Qt／Web 對同一檔比對游標、量測、FFT、RF 跳峰、兩種 CSV）。人工互動與真機項目不可標成自動驗證通過。
  4. 回退（代價由小到大）：pywebview／WebView2 出問題 → python3 -m scope_tool.web.app --browser；Web 版不行 → 雙擊 _qt.command；Qt 已刪 → git checkout qt-final -- scope_tool/ui scope_tool/main.py。
  5. 觸發回退的條件：原生 WebView 不穩；游標／Track RF 數值與 Qt 不一致；大檔記憶體超預算；儀器操作順序、逾時清理或 STOP 行為回歸失敗；Windows 打包缺資源或 VISA 連不上。
