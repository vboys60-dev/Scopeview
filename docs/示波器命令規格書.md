# Keysight 示波器 SCPI 命令規格書

> 開發規範文件。所有示波器截圖/資料擷取功能開發須遵循本規格。
> 涵蓋機型：3000G/3000X（非PC Base）、EXR/MXR/S系列（PC Base）

## 機型差異總表

| 項目 | 3000G/3000X | EXR/MXR/S系列 |
|---|---|---|
| 截圖命令 | `:DISPlay:DATA?` | `:DISPlay:DATA?`（參數更多） |
| 波形直讀 | `:WAVeform:DATA?` | `:WAVeform:DATA?`（相同） |
| 本機存檔位置 | USB隨身碟 (`\usb\`) | 硬碟 (`C:\Users\Public\Documents\Infiniium\`) |
| 存檔命令 | `:SAVE:WAVeform` / `:SAVE:IMAGe` | `:DISK:SAVE:WAVeform` / `:DISK:SAVE:IMAGe` |
| 取檔命令 | 無需（PC讀取即直傳） | `:DISK:GETFILE?` |
| RAW波形最大點數 | 4M（類比）/8M（數位） | 依機型，通常更大 |
| CSV大點數風險 | 同左 | 同左（>100k點禁用CSV，見六） |

## 一、截圖

```scpi
:DISPlay:DATA? [<format>][,<palette_or_mode>...]
```

**3000G**：`:DISPlay:DATA? PNG,COLor`
**EXR/PC**：`:DISPlay:DATA? PNG,SCReen,ON,NORMal`（type,screen_mode,compression,inversion）

必做前置：
```scpi
:HARDcopy:INKSaver OFF   # 3000G，否則截圖是白底反白
```
- `inversion=INVert`（EXR）等效省墨白底，用於報表列印
- 回傳為 IEEE488.2 binary block，PyVISA `query_binary_values(datatype="B")` 直接拿 bytearray 存檔

**EXR 存檔轉取法（需嵌入設定資訊或留存log時才用）**：
```scpi
:DISK:SAVE:IMAGe "<path>",PNG,SCReen,ON,NORMal
:DISK:GETFILE? "<path>"
:DISK:DELete "<path>"
```

**規則**：預設一律用 `:DISPlay:DATA?` 直接截圖，不用存硬碟法（多一趟I/O、需自行清理殘留檔）。

## 二、波形資料直讀（兩機型命令相同）

```scpi
:STOP                            # 確保數據穩定，直讀前必做
:WAVeform:SOURce CHANnel1
:WAVeform:FORMat BYTE            # BYTE最快 / WORD高解析 / ASCii免換算但巨量文字
:WAVeform:POINts:MODE RAW        # RAW=底層完整採樣，需STOP狀態；NORMal=螢幕1000點
:WAVeform:POINts 100000          # 要求點數（1000的整數因數，或MAXimum）
:WAVeform:UNSigned ON            # 配合BYTE用無號整數
:WAVeform:PREamble?              # 必查，取換算係數
:WAVeform:DATA?                  # 讀二進位波形點
:RUN                             # 讀完恢復運行
```

### PREamble 10參數（逗號分隔）

| idx | 名稱 | 用途 |
|---|---|---|
| 0 | FORMAT | 0=BYTE,1=WORD,4=ASCII |
| 1 | TYPE | 取樣類型 |
| 2 | POINTS | 實際傳回點數 |
| 3 | COUNT | 平均次數 |
| 4 | XINCREMENT | 時間間隔(s/點) |
| 5 | XORIGIN | 時間起點(s) |
| 6 | XREFERENCE | 時間參考索引（通常0） |
| 7 | YINCREMENT | 電壓/階(V) |
| 8 | YORIGIN | 電壓基準(V) |
| 9 | YREFERENCE | 電壓參考索引 |

### 換算公式（唯一標準，全機型通用）

```
Time[i]    = (i - XREFERENCE) * XINCREMENT + XORIGIN
Voltage[i] = (DataValue[i] - YREFERENCE) * YINCREMENT + YORIGIN
```

## 三、記憶體深度設定（波形直讀前，需要指定點數時才做）

```scpi
:ACQuire:POINts:AUTO OFF               # 手動指定點數前必關自動
:ACQuire:POINts[:ANALog] <n>|MAX|AUTO  # 硬體擷取記憶深度
:ACQuire:POINts[:ANALog]?              # 查詢實際點數
:ACQuire:POINts:MAXimum?               # 查詢硬體上限
```

**規則**：點數與取樣率互斥連動——指定點數則取樣率被限制，反之亦然。單次擷取流程：
```scpi
:ACQuire:POINts:AUTO OFF
:ACQuire:POINts:ANALog 1000000
:STOP
:SINGle
*OPC?          # 等擷取完成，回傳1才能繼續
```

## 四、檔案匯出（CSV / H5 / H5INt）

```scpi
# 直讀後PC端自存，或用DISK/SAVE子系統讓示波器直接產檔：
:DISK:SAVE:WAVeform <source>,"<path>",<format>[,<header>]   # EXR/PC
:SAVE:WAVeform:FORMat <format>                               # 3000G
:SAVE:WAVeform:STARt "<path>"                                 # 3000G觸發
```
`<source>`: `CHANnel1`~`8` | `ALL`（單檔含全通道）
`<format>`: `CSV` | `H5` | `H5INt` | `BINary` | `TSV` | `MATlab`

### 格式選型規則（強制）

| 點數規模 | 格式 | 理由 |
|---|---|---|
| < 100k | CSV可用 | 檔案可控（數MB內），可讀 |
| ≥ 100k | **禁用CSV，用 H5INt** | 10M點CSV可達300~500MB且寫入耗時數十秒；H5INt同等資料僅約20MB，<1秒寫完 |
| 需真實電壓浮點 | H5 | 數值即電壓，免換算 |
| 需最小檔案+高速 | H5INt | int16量化碼，需下方公式換算 |

### H5 內部結構
```
/FileType                          -> 'Keysight Waveform'
/Frame                             -> Model, Serial, Date
/Waveforms/Channel<N>              -> attrs: NumPoints, XInc, XOrg, YInc, YOrg, YReference, XUnits, YUnits
/Waveforms/Channel<N>/Channel<N>Data -> 數據陣列（H5=float直接電壓；H5INt=int16需換算）
```

H5INt 換算（與波形直讀公式一致）：
```
Voltage = (RawValue - YReference) * YInc + YOrg
```

### 完整取檔流程（EXR/PC，3000G由PC直接讀不需GETFILE）
```scpi
:DISK:SAVE:WAVeform CHANnel1,"C:\...\export.h5",H5
*OPC?                              # 等示波器寫檔完成，必做
:DISK:GETFILE? "C:\...\export.h5"  # 二進位取回
:DISK:DELete "C:\...\export.h5"    # 用完必刪，防塞爆示波器硬碟
```

## 五、IEEE488.2 二進位區塊格式（自動處理，了解即可）

```
#<N><Length><Binary Data><\n>
```
`#`起始 → `<N>`長度欄位的字元數 → `<Length>`實際資料位元組數 → 二進位內容 → 換行結尾。
PyVISA `query_binary_values()` / `read_bytes_block()` 自動解析，不需手動剝除。

## 六、通訊與例外規則（強制遵守）

1. **Timeout**：截圖/一般查詢 ≥10~15秒；大點數存檔/傳輸(H5/CSV) ≥30~60秒
2. **RDP衝突**：Windows遠端桌面連線示波器時執行截圖或存檔會噴 Error 273 → 執行自動化前先關RDP，改用Web介面
3. **路徑跳脫**：Windows路徑一律用raw string `r"C:\..."` 或雙反斜線
4. **暫存檔清理**：任何 `:DISK:SAVE:*` 產生的檔案，`:DISK:GETFILE?` 取回後必須 `:DISK:DELete`
5. **大點數禁用CSV**：見四之格式選型規則
6. **直讀前必須STOP**：`:WAVeform:DATA?` 讀取前示波器須處於STOP，否則數據不穩定
7. **寫檔須等OPC**：`:DISK:SAVE:*` / `:SINGle` 後一律 `*OPC?` 等待完成再進行下一步

## 七、Python 標準範本（PyVISA）

### 7.1 截圖
```python
import pyvisa
rm = pyvisa.ResourceManager()
scope = rm.open_resource("TCPIP0::<ip>::inst0::INSTR")
scope.timeout = 15000
scope.write(":HARDcopy:INKSaver OFF")  # 3000G專用；EXR用inversion參數
img = scope.query_binary_values(":DISPlay:DATA? PNG,SCReen,ON,NORMal", datatype="B", container=bytearray)
open("shot.png", "wb").write(img)
scope.close()
```

### 7.2 波形直讀 → CSV
```python
import numpy as np, pyvisa
rm = pyvisa.ResourceManager()
scope = rm.open_resource("TCPIP0::<ip>::inst0::INSTR")
scope.timeout = 20000
try:
    scope.write(":STOP")
    scope.write(":WAVeform:SOURce CHANnel1")
    scope.write(":WAVeform:FORMat BYTE")
    scope.write(":WAVeform:POINts:MODE RAW")
    scope.write(":WAVeform:POINts 100000")
    scope.write(":WAVeform:UNSigned ON")

    pre = [float(x) for x in scope.query(":WAVeform:PREamble?").split(",")]
    x_inc, x_org, x_ref = pre[4], pre[5], pre[6]
    y_inc, y_org, y_ref = pre[7], pre[8], pre[9]

    raw = np.array(scope.query_binary_values(":WAVeform:DATA?", datatype="B", is_big_endian=True), dtype=np.float64)
    idx = np.arange(len(raw))
    t = (idx - x_ref) * x_inc + x_org
    v = (raw - y_ref) * y_inc + y_org

    np.savetxt("waveform.csv", np.column_stack((t, v)), delimiter=",",
               header="Time (s),Voltage (V)", comments="")
finally:
    scope.write(":RUN")
    scope.close()
```

### 7.3 大點數存H5取回（EXR/PC，>100k點時用這個而非7.2）
```python
import pyvisa
rm = pyvisa.ResourceManager()
scope = rm.open_resource("TCPIP0::<ip>::hislip0::INSTR")
scope.timeout = 30000
remote = r"C:\Users\Public\Documents\Infiniium\tmp.h5"
try:
    scope.write(":ACQuire:POINts:AUTO OFF")
    scope.write(":ACQuire:POINts:ANALog 1000000")
    scope.write(":STOP")
    scope.write(":SINGle")
    scope.query("*OPC?")

    scope.write(f':DISK:SAVE:WAVeform CHANnel1,"{remote}",H5')
    scope.query("*OPC?")

    data = scope.query_binary_values(f':DISK:GETFILE? "{remote}"', datatype="B", container=bytearray)
    open("waveform.h5", "wb").write(data)

    scope.write(f':DISK:DELete "{remote}"')
finally:
    scope.write(":RUN")
    scope.close()
```

H5解析：
```python
import h5py, numpy as np
with h5py.File("waveform.h5", "r") as f:
    ch = f["Waveforms/Channel 1"]
    raw = np.array(ch["Channel 1Data"])
    v = raw if np.issubdtype(raw.dtype, np.floating) else \
        (raw - ch.attrs["YReference"]) * ch.attrs["YInc"] + ch.attrs["YOrg"]
    t = ch.attrs["XOrg"] + np.arange(len(raw)) * ch.attrs["XInc"]
```

## 八、決策速查

| 需求 | 用法 |
|---|---|
| 螢幕截圖 | `:DISPlay:DATA?` 直傳，不存硬碟 |
| <100k點波形 | `:WAVeform:DATA?` 直讀 + PC端存CSV |
| ≥100k點波形 | `:DISK:SAVE:WAVeform ...,H5INt` 存檔後 `GETFILE?` 取回 |
| 多通道同時存 | `source=ALL` |
| 需完整PDF報告 | `:DISK:SAVE:MREPort "<file>.pdf"` |
| 需還原示波器現場設定 | `:DISK:SAVE:COMPosite "<file>.osc"` |
