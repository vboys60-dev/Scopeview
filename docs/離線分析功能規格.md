# 離線分析功能規格（依 Keysight Infiniium Offline 手冊，Claude × Codex 討論定案）

手冊：`/Users/lianshi/Downloads/scope-gui-key/Keysight Infiniium Offline Oscilloscope Analysis Software Help/contents/*.htm`
使用者決定：電壓量測、時間量測、FFT、數學／濾波四類全做；用途（電源紋波、數位時序、頻譜）都要；
接受與 Infiniium 數值有差異，但畫面要標明；分析頁改成類似 Infiniium 的版面，舊版面不保留。

## 演算法（`scope_tool/analysis/`，只用 numpy）

- `measure.py`：輸入驗證（長度一致、有限值、時間遞增）、top/base 直方圖法（上下各 40%，
  眾數次數 < 5% 退回 max/min）、電壓量測（Vmax、Vmin、Vp-p、Vtop、Vbase、Vamp、Vavg、
  Vrms(DC)、Vrms(AC)）、量測清單與分派、統計（目前／平均／最小／最大／範圍／標準差／次數）。
- `edge.py`：閾值 10/50/90 或 20/50/80（% of top-base）；邊緣須依序穿越下中上閾值、線性內插；
  上升／下降時間與斜率（邊緣 ≥ 4 點）；週期、頻率用同極性相鄰邊緣（預設上升，可選下降），
  頻率逐週期取倒數；±寬度、工作週期逐週期配對，只算完整週期；
  過衝（Overshoot）＝邊緣後到平台中點的局部極值，前衝（Preshoot）＝平台中點到邊緣前的局部極值，
  皆除以 top−base。量測不出來時回傳原因。
- `mathfn.py`：加減乘除（時間軸不同時只取重疊區、B 內插到 A，不外插；除以 0 → nan）、
  反相、絕對值、平方、開根號、log10（以 1 個單位為參考，結果無單位）、微分、積分；推導單位。
- `filter.py`：低通＝4 階 Bessel-Thompson，H = 105 / P(j·2.1139·f/fc)，
  P(s)=s⁴+10s³+45s²+105s+105，補償群延遲；高通＝單極 jω/(jω+ωc)；平滑＝N 點移動平均。
  頻域套用，兩端以邊值補長（依 fc 決定長度），註明邊界效應。
- `fft.py`：Rectangular、Hanning、Hamming、Flattop、Blackman-Harris；
  單位 dBm（預設）、Vrms、dBV、dBmV、dBµV、W，參考阻抗預設 50 Ω；不補零；
  回傳 Δf、ENBW；前 5 峰值；點數上限 2²⁴；須等距取樣。

## 版面（`scope_tool/ui/analysis_*.py`）

- 上方工具列（`analysis_controls.py`）：開啟、檔案資訊、重設視圖、通道歸位、游標歸位、匯出（選單內為原匯出列）、
  數學…、FFT 開關、閾值、量測範圍（游標區間／全部）、預覽、取樣率與點數摘要；放不下收進溢出選單。
- 左側直立分頁「時間量測／電壓量測」（`analysis_controls.py`）：點一下＝對目前選取通道加一筆量測，
  來源與邊緣方向在加入時固定。
- 通道列＋水平列（`analysis_chanbar.py`）：每通道色塊（顯示勾選、V/格、位置格數、雙擊換色、選取外框），
  F1/F2 同樣有色塊與刪除鈕；V/格（單位 V）只用查表檔位
  500 µV、2 mV、5 mV、10 mV、20 mV、50 mV、100 mV、200 mV、500 mV、1 V、2 V、5 V、10 V，
  其他單位用 1-2-5；水平列＝時間/格與中心位置，與主圖雙向同步。
- 主波形格（`analysis_plot.py`）：10×10 格；滾輪換 V/格前判斷，新檔位會讓波形超出 ±5 格就不放大；
  縮放以波形目前中心為準；示波器模式互動保留。
- FFT 頻譜格（`analysis_fftplot.py`）：FFT 開啟才出現，可拖分隔線；背景計算，舊結果丟棄。
- 結果區（`analysis_results.py`）：量測表（量測｜目前｜平均｜最小｜最大｜範圍｜標準差｜次數，
  右鍵刪除、清除全部、匯出結果 CSV）、游標表（t1、t2、Δt、1/Δt、v1、v2、ΔV、換算來源、各通道 @t1/@t2/Δ）、
  FFT 峰值表（Δf、ENBW、視窗、未補零）；可收合；窄視窗改分頁。
- 數學對話框（`analysis_math.py`）：產生 F1、F2…，單位由分析頁的 {通道: 單位} 記錄；匯出 CSV 只含原始通道。

「目前」欄：逐事件量測取範圍內最左邊的完整有效事件，整段量測取範圍結果；重算不累加次數
（Infiniium 的 Current 是最近一次擷取，離線單檔沒有對應概念）。

## Jitter／眼圖（2026-10-17 第二輪，Claude × Codex 討論定案）

> 已於 2026-10-22 移出 GUI，程式碼暫存未接線

單一波形檔即可（Infiniium Real-Time Eye 本來就是折疊單次深擷取）。全部標明「固定頻率還原、近似、與 EZJIT 可能不同」。

- `clock.py` 時脈還原（只做固定頻率）：全自動（時脈＝同方向週期中位數；資料＝最窄脈衝）、半自動（標稱速率當起點再擬合）、
  手動（UI 固定只估相位）。時脈與 NRZ 共用：相鄰邊緣間隔 ÷ UI 四捨五入累加成整數格號（錯一格不往後傳），
  中心化最小平方擬合 UI、t0，重複到格號不變（最多 10 次，否則報失敗）；TIE 平均為 0。
  單邊時脈 UI＝週期、兩邊時脈 UI＝半週期（保留 DCD）、資料一律兩種邊緣。
  只警告不判失敗：半格附近間隔 > 1%、缺邊、資料全偶數 UI（速率歧義）、TIE p-p > 0.5 UI、每 UI < 4 點、邊緣 < 1000。
- `jitter.py`：TIE（時脈／資料）、N 週期、Period-Period（Pₖ₊ₙ − Pₖ 逐週期滑動）、±寬度差（相鄰週期脈寬相減）、
  還原 UI、還原速率。N 週期等只用時脈型且不跨缺邊；統計沿用量測表（標準差＝RMS、範圍＝p-p）。
- `eye.py`：Vtop／Vbase＝UI 40–60% 樣本以中閾值分兩群；眼高＝(Vtop−3σ)−(Vbase+3σ)；Q＝(Vtop−Vbase)/(σtop+σbase)；
  交叉點＝TIE 迭代縮窄到 ±3σ（保留 < 95% 時警告離群／多峰）；眼 Jitter RMS＝σ、p-p＝6σ（手冊）；眼寬＝UI−6σ；
  Crossing %＝每個 UI 在交叉時間內插出的電壓取中段直方圖眾數（沒有明顯峰報無法判定）；DCD＝上升／下降 TIE 中位數差。
  色階圖：相位折疊到 −0.5～1.5 UI，相鄰取樣線性補點只供顯示（總點數上限 5e7、分塊累加，不截記錄），對數色階、黑底。
- 介面：工具列「Jitter」「眼圖」開關、「時脈…」設定（訊號類型、邊緣、速率模式、標稱速率、N，全頁共用）；
  左側量測欄第 3、4 頁「Jitter」「眼圖」；Jitter 格＝TIE 趨勢（缺邊斷開）＋直方圖；眼圖格＝色階圖；
  兩格與量測表共用來源範圍（游標區間／全部）與時脈設定；眼圖量測不必開眼圖格也會算。
- 檔案：`analysis/{clock,jitter,eye}.py`、`ui/analysis_{jitter,eye,runner,layout}.py`（runner、layout 自 controls／tab 拆出）。
  analysis_runner.py、analysis_layout.py 仍為一般量測／版面使用，不屬未接線範圍。
- 延後：資料型 N-UI／UI-UI、Explicit 外部時脈、PLL／SSC 追蹤、Jitter 頻譜、實測眼高、sinc 內插、RJ/DJ 分解、BER 浴缸、
  遮罩、等化、PAM、跨擷取累積。
