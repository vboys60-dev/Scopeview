## 2. 設計

### 2.1 版面：同一頁左右兩區（窄時自動上下）
```
┌ 連線列（全域，不變）───────────────────────────────┐
├ [資料截取] [離線分析] [FFT 頻譜]                     ┤
│ ⚠ 尚未連線，請先在上方連線儀器。（只一份，跨兩欄）    │
│ ┌ 截圖 ──────────────┐ ┌ 波形擷取 ──────────────┐ │
│ │ 目錄／前綴／格式…   │ │ 資料夾／檔名／通道／點數 │ │
│ │ [開始存圖][複製][另存]│ │ [開始擷取] 狀態          │ │
│ │ 預覽圖              │ │ [用分析頁開啟]           │ │
│ └────────────────────┘ └────────────────────────┘ │
```
- 理由：兩邊都是短表單，左右並排不用捲動就看得到兩個主按鈕；上下排的話截圖預覽（最高 60vh）會把擷取區推到畫面外。頁內子切換等於把舊分頁換個地方放，沒解決問題。
- 實作：CSS grid `repeat(auto-fit, minmax(440px, 1fr))`。1000 寬視窗（內容約 976px）仍是兩欄，窄到約 900px 以下自動變上下，不寫 media query。
- 共用控制只留一份：連線列本來就一份；「未連線提示」移到容器，截圖區刪掉自己的那份。擷取區的狀態文字「尚未連線」是它的狀態列，保留。兩組資料夾**不合併**（開放問題 Q2）。

### 2.2 模組策略：新容器掛兩個舊模組，內部邏輯不重寫
- 新檔 `static/js/tab_datacapture.js`（約 25 行）：`import { mount as mountShot } from "./tab_screenshot.js"`、`import { mount as mountCapture } from "./tab_capture.js"`；建立提示＋grid＋兩張卡片（`h2` 標題＋內容 div），分別呼叫 `mountShot(body, ctx)`、`mountCapture(body, ctx)`。每張卡片各自 `try/catch`，一邊掛載失敗只在該卡片顯示「（截圖模組尚未載入：…）」，不拖垮另一邊（沿用 `main.js mountAll` 的做法）。
- **必須傳同一個 `ctx` 物件**（不可複製），`main.js` 改 `ctx.activeTab` 時擷取區才看得到。
- **分頁 id 沿用 `capture`**：按鈕 `data-tab="capture"`、section `#tab-capture`，只把標籤改成「資料截取」、`MODULES.capture.src` 指向新容器。這樣：
  - `tab_capture.js` 一行都不用改（`active()` 與 `tab.activated` 判斷仍是 `"capture"`），**不需要任何轉發**；
  - `float_check.mjs`、`browser_float_checks.py`、`browser_check.py:129` 不用改；
  - 代價只是 id 與檔名不同名（`capture` vs `tab_datacapture.js`），在容器檔頭註明。
- **初始分頁**：`ctx.activeTab` 預設改 `"capture"`，否則初始 `tab.activated("screenshot")` 不會觸發擷取區查通道，要等使用者重連才載入。
- 提示：容器 `bridge.on("driver", ev => hint.hidden = !!ev.connected)`，初值取 `ctx.appState?.connected`。

### 2.3「移除多餘分頁」的定義
- 頂層分頁最終只剩：**資料截取**（`capture`）、**離線分析**（`analysis`）、**FFT 頻譜**（`fft`，FFT 任務新增），依此順序。
- 刪除：`data-tab="screenshot"` 按鈕、`#tab-screenshot` section、`MODULES.screenshot`。
- `tab_screenshot.js`、`tab_capture.js` **保留為內部模組**（L2／L3 擁有權不變，`l2_check`／`l3_check` 不動）。不刪、不改名。

## 6. 風險與開放問題

風險：
- `activeTab` 預設沒改 → 初始不查通道。已在 S1 用 `browser_check` 新步驟擋。
- 同頁兩個動作搶儀器鎖：後端回 BUSY，兩邊已有文案；只有紙上與 mock 驗證，真機未驗。
- 截圖預覽在半寬欄內變小（仍 `max-width:100%`）；1000 寬時約 460px 寬。
- Qt 版（`scope_tool/ui/`，凍結）仍是兩個分頁，兩版介面不同。

開放問題（括號內為建議預設，未回覆就照做）：
1. 版面左右並排、窄窗自動上下？（是）
2. 截圖與擷取共用同一個存檔資料夾？（否，維持兩組設定鍵與兩個「瀏覽…」，行為不變）
3. 一邊執行中時停用另一邊的按鈕？（否，靠既有 BUSY 提示）
4. 內部分頁 id 沿用 `capture`，不改成 `datacapture`？（沿用；要改名需多動 `tab_capture.js` 2 行與兩支測試）
5. 分頁順序 資料截取／離線分析／FFT 頻譜，啟動預設停在資料截取？（是）
6. 左右哪邊放截圖？（截圖左、擷取右）
