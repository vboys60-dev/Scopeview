## 0. 一頁結論

1. **根本問題**：同一個手勢（拖曳／滾輪）會因「剛好有沒有點到曲線」而變成完全不同的動作；加上 FFT 與 B 區把 C 區擠到約 130 px，所以「不順手」。
2. **操作模型**：拖曳一律只平移時間；框選放大有固定可見的模式按鈕；垂直位置只由「通道零位把手」調整；滾輪只依「區域」決定意義。
3. **Zoom In**：做水平框選放大＋視圖 Undo/Redo；**不做** N8900A 的上下雙格 Zoom Mode（空間不足，現有 overview 縮圖已承擔「全景＋縮放框」）。
4. **時間軸／電壓軸**：新增 Horizontal 列（時間/格、中心位置）與選取通道的 Vertical 欄位；左軸改標實際電壓；修正刻度標籤重複（目前實測 11 個標籤出現連續三個「196 µs」、五個「196.1 µs」）。
5. **Marker**：格外把手、最近者優先命中、Y 以物理值為真值、來源與「目前選取通道」脫鉤、圖框旁固定摘要＋B 區「游標」分頁。
6. **A／B／FFT**：三條可拖曳且可收折的 splitter；主圖格內高度硬下限 240 px、預設目標 ≥300 px；FFT 計算開關與窗格可見性分開。
7. **分期**：P1 小修（零新 UI）→ P2 Zoom＋H/V 欄位＋splitter → P3 Marker 語意。每期可獨立回退。

## 2. 討論結論

### 2.1 雙方一致（直接採用）

- 手勢依「區域＋可見模式」決定，**曲線命中只用於單擊選取**，不再決定拖曳或滾輪語意。
- 移除兩個舊手勢：①滾輪在曲線上改 V/格 ②Shift＋拖曲線改 dx（dx 改放欄位）。
- 滾輪依位移量縮放、先正規化 `deltaMode`；純橫滑不縮放。
- 視圖 Undo/Redo（約 50 步，連續操作 250–300 ms 合併），只記時間視窗與通道 scale/position；歷史經既有意圖事件套用，不直接寫通道。
- 垂直位置用「具名零位把手」（越界貼邊顯示箭頭、仍可拖）。
- 垂直框選／縮放一律取「能容納目標範圍的最小合法檔位」，不開放任意 Fine（`V_TABLE` 非完整 1-2-5）。
- 嚴格相鄰檔位純函式（`step125Strict`）。
- Track Measurements 在選單中 **disabled** 並說明原因（後端無事件座標，不是純前端工作）。
- 游標來源與 `selected` 脫鉤；Y 以物理值為真值，store 內格數只是投影。
- B 區改分頁：量測結果｜游標｜FFT 峰值。
- 時間刻度位數依格距推導、同一 SI 前綴；必要時以中心為基準標相對偏移。
- 拆開「FFT 計算」與「FFT 窗格可見」；移除 `scrollIntoView`；新結果不得重開已收起的窗格。
- 雙格 Zoom：**不做**（Codex 撤回其第一輪 P3）。
- 持久化：本期只保證**同次執行內**；跨啟動為待決策項（見 §8）。

| 議題 | Opus 第 1 輪 → 最終 | Codex 第 1 輪 → 最終 | **裁決** | 理由 |

- 主圖分區：**格內**、**左垂直刻度區**、**下時間刻度區**、**上緣 X 把手列**、**右緣 Y 把手列**；縮圖獨立。

### 3.3 縮放界線與歷史

- 最小跨度：同時考量取樣間隔與浮點精度（約 10 個取樣間隔，並保證 `t0<t1`）；最大跨度：全長 ×10。
- 移除 `fits` 限制：使用者刻意放大時允許超出畫面，提示並提供「適配此通道」。
- 主圖／縮圖拖曳期間忽略主圖滾輪；框選門檻為 6px。
- 歷史：一次拖曳、一串滾輪（停止 ~300 ms）、一次欄位提交各算一步；換檔清空。

## 4. 時間軸／電壓軸

### 4.1 Horizontal 列（主圖下方，單列約 28 px）

```
[✥|⬚] [↶][↷][完整時間] │ 時間/格 [◀][ 20 ns ][▶] │ 位置(中心) [◀][ 196.1023 µs ][0][▶] │ 範圍 196.0023–196.2023 µs │ 游標摘要
```

- `時間/格 S = (t1−t0)/10`；`位置 P = (t0+t1)/2`，為參考點（寫死中心 r=0.5）的檔案時間；`t0 = P − r·10S`、`t1 = P + (1−r)·10S`。
- 點欄位可直接輸入（沿用 `parseSI`，「20n」「20 ns」皆可）；時間/格的 ◀▶ 與滾輪走 `step125Strict`，位置的 ◀▶ 與滾輪每次移動 ±S（含位置 0）；框選／滾輪得到的非標準尺度如實顯示，不強制吸附。
- 欄位與範圍文字依 S 的千分之一解析度四捨五入顯示，不改視圖真值；有焦點但未編輯時，Enter／blur 也重繪最新值。
- 「完整時間」取代含糊的「重設視圖」（它只動時間範圍）。「0」＝把檔案時間 0 放到中心，若 0 不在檔案範圍則禁用。

### 4.2 Vertical 欄位（併入通道列右側，只作用於目前通道）

```
作用中 ●CH1 │ 單位/格 [▼][ 200 mV ][▲] │ 中心電位 [▼][ −1.20 V ][歸零][▲] │ dx [ 0 s ] │ [適配]
```

- `中心電位 O = −position × scale`；store 仍存格數 `position`（契約不動）。
- 衍生通道顯示實際單位（V²/格、V/s/格…），不一律寫 V。
- 換檔基準＝**畫面中心**（修正 `rescale()`）；▲▼ 文字改「較矮／較高」。
- 通道 chip 瘦身為 `[☑ ●CH1 200 mV/格]`；點擊選取、雙擊換色；`dx` 移入欄位並在非零時顯示徽章，標示「會影響游標區間量測與 FFT」。

### 4.3 軸上顯示

- **時間軸**：位數依格距推導（`digits ≈ floor(log10(max|v|)) − floor(log10(step)) + 2`，上限 9）、11 個標籤同一 SI 前綴；小於半格距 ×1e-9 的值當 0；需超過 6 位有效數字時，中心標全精度絕對值、其餘標相對中心偏移；文字太密時隔格標，格線仍 10 格。格式化只影響文字，不回寫數值。
- **電壓軸**：左軸顯示目前通道的實際電壓（通道顏色、標題帶通道名＋單位/格）；左邊界寬度依文字測量，不再固定 44 px；無目前通道才退回格數。
- **零位把手**：每個可見通道一個（顏色＋名稱／形狀，不只靠顏色）；超出視窗貼邊顯示 ▲▼。
